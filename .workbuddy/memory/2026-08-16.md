## China Select（中国精选）概念澄清
- 用户在构思"China Select / 中国精选"策展/平台型生意：精选中国品牌（老字号 + 海尔/大疆/美的/格力等现代冠军），并想加招商CTA"想成为这个也来联系我"。

- 确定的变现顺序：先路径A（淘宝联盟/淘宝客带货赚佣金，不进货），跑出真实成交与流量后，再路径B（品牌招商/撮合抽佣），此时"联系我"CTA才成立。
