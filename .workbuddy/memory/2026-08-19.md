## 用户提出"自填充"方案（重要决策点，已否决）

用户想：前期没商家入驻 → 把自己控制的五六家公司全写进 China Selection 当入驻商家，每家负责不同产品、各做一个网站，营造"天然信赖"，并想要"每家后台发布产品 + AI 从别处链接 copy 上架"功能。

**我的判断：不 OK，会反噬信任。** 这等于把"独立策展"变成"自家橱窗"，是早年毙掉的"自认证/自夸"升级版。

**替代方案（已给）：拆分两件事**
- A = China Selection 策展/流量入口：保持独立第三方，冷启动用可公开引用、注明来源的真实品牌（Roborock/Dreame 等），不塞自己公司。
- B = 用户自己的供应网络：透明标注"关联公司/出口实体"，每家挂各自网站+产品线（可放 chinabrand.com），诚实标注比伪装强。
- "商家后台 + AI 导入链接上架"功能应建在 B，不建在 A；且导入必须限定自有/授权内容，无授权抓第三方=侵权。

**用户已确认（2026-08-19 晚）：五六家公司是真实出口实体；要 A 和 B 都要但分开。**
→ 已写 `china_select_architecture.md`：A=China Selection 独立策展引流（不塞自家公司）；B=Supply Network 透明供应网络（诚实标注关联、每家有 vendor 后台+AI从链接导入上架，但导入只限自有/授权内容）。
→ A↔B 单向导流（A 引流→B 接单→Escrow.com 收口）。B 后台是工程活，建议作为独立项目迭代。
→ **用户进一步提议：把自家公司做成「Sponsored 赞助商」付费广告、而非"关联实体"**。已采纳并修订架构文档：赞助区与编辑策展区物理分隔+角标 Sponsored+标注 affiliated sponsor；赞助商不进策展清单/不带 Selected 徽章；"担保感"靠 Escrow.com 托管而非伪装独立。
→ 已把 Sponsored Partners 区加入 MVP 页面（红框虚线分隔、Sponsored·affiliated 角标、披露付费+关联+escrow、6 张占位卡含品类/网站），推 GitHub。待用户填真实公司名/网站/品类。
